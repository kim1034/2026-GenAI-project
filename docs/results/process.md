V1.4 완료는 원래 계획의 모든 가설이나 원논문 재현의 완료를 의미하지 않는다. A(T=0.5)와 B(Uniform)는 test에 실행하지 않았다. Greedy(T=0)는 A가 아니며 E는 Uniform이 아니다.

시험 종료 후 프로젝트 밖 GPU 작업을 관찰했다. 설치자·소유자·과거 결과나 D 중단에 대한 인과 영향은 확인하지 못했다. 파일 해시 보존은 확인했지만 실행 환경 전체의 무결성·독점 사용을 증명하지 않는다. 이 환경의 경과 시간을 전용 GPU 처리율로 일반화하지 않는다.

GPU 반납은 사용자 직접 수행 대상이며 실제 반납 완료 여부는 확인하지 않았다. 추가 GPU 실행이나 자동 반납은 수행하지 않았다. [기록 양식](record-template.md)은 후속 실행을 위한 빈 양식이다.
