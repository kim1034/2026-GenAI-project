# GUE와 Gaussian 교란을 이용한 오류 탐지 실험 결과

작성일: 2026-11-16 (한국시간)  
실험 범위: 승인된 V1.4 최종 시험  
설계·최종 해석: Astra(AI), 코드·실행·백업 검증: Sol

## 핵심 결론

**이번 모델·데이터·고정 설정에서 GUE(D)와 Gaussian(C)의 오류 탐지 AUROC가 사전에 정한 허용 차이 ±0.02 안에서 실용적으로 동등하다는 결과를 얻었다.**

주 비교인 D−C의 AUROC 차이는 **−0.001735**, 95% 신뢰구간은 **[−0.012643, 0.009019]**이다. 신뢰구간 전체가 사전 동등성 범위 [−0.02, 0.02] 안에 있으므로, 등록된 8가지 판정 규칙 중 **7번, PR6 ‘확인’**에 해당한다.

이 결과는 단순히 차이를 발견하지 못했다는 결과보다 구체적인 정보를 제공한다. 다만 GUE와 Gaussian이 완전히 같거나, 다른 모델·과제·설정에서도 동등하다는 의미는 아니다. GUE의 우월성을 확인한 결과도 아니다.

| 실용적 동등성 기준 | AUROC 차이 ±0.02 |

주 지표는 **두 묶음 AUROC의 평균**이다. 두 묶음의 엔트로피를 먼저 평균한 뒤 계산한 AUROC와 구분한다. 공통 α는 C 기준 개발 절차로 선택했으며, 각 조건을 별도로 최적화한 최대 성능 비교는 아니다.

| 조건 | 의미 | 완료 문항 | 완료 응답 |
| --- | --- | ---: | ---: |
| Greedy | 교란 없는 결정적 생성, 오류 라벨 기준 | 1,319 | 1,319 |
| C | Gaussian 교란 | 1,319 | 21,104 |
| D | GUE 교란 | 1,319 | 21,104 |

전체 시험 응답은 **64,631개**이며, 네 조건의 완료 여부와 원본 무결성을 검증했다.

## 조건별 결과

AUROC·AUPRC와 8응답 다수결 정확도는 두 묶음의 평균이다. INVALID와 잘림 비율은 생성 응답 기준이다.

| 조건 | AUROC | AUPRC | 8응답 다수결 정확도 | INVALID | 잘림 |
| --- | ---: | ---: | ---: | ---: | ---: |
| C: Gaussian | 0.865086 | 0.711617 | 76.1183% | 4.9280% | 0.2748% |
| D: GUE | 0.863351 | 0.715167 | 77.2176% | 4.7290% | 0.2180% |
| E: 주변분포 독립 대조군 | 0.860776 | 0.712165 | 76.6869% | 4.5915% | 0.2180% |

D의 AUPRC와 다수결 정확도가 수치상 높지만, 이 지표들에 대한 우월성을 확증한 것으로 해석하지 않는다. 주 결론은 사전에 등록한 D−C AUROC 비교에 따른다.

## 비교 분석

| 비교 | AUROC 차이 | 95% 신뢰구간 | 표준오차 | 분석 지위·해석 |
| --- | ---: | --- | ---: | --- |
| D−C | −0.001735 | [−0.012643, 0.009019] | 0.005539 | 유일한 확증 비교; 사전 기준 내 실용적 동등성 확인 |
| D−E | 0.002574 | [−0.008784, 0.014212] | 0.005830 | 기술적 비교; 신뢰구간이 0 양쪽에 걸침 |
| E−C | −0.004310 | 계산하지 않음 | 계산하지 않음 | 점추정만 보고 |

D−C와 D−E는 문제 단위의 짝지은 bootstrap으로 각각 10,000회 시도했으며, 두 비교 모두 유효 10,000회·제외 0회였다. 신뢰구간은 percentile 95%이며, 등록된 RNG 키는 각각 `[10, 1]`, `[10, 2]`이다. E−C에는 등록된 bootstrap 키가 없어 신뢰구간·표준오차·확증 판정을 부여하지 않았다.

D−E 결과만으로 GUE의 주변분포를 넘어선 구조 효과를 확증하지 않는다. K에 따른 성능 곡선도 기술 결과이며, 이를 보고 주 분석의 K를 사후 변경하지 않았다.

## 수행 완료 및 추가 실험 판단

개발 실험과 α 선택, 설정 봉인(LOCK), CPU 분석 파이프라인 점검, Greedy·C·D·E 본시험, 등록된 최종 분석, Astra의 최종 해석을 완료했다. D 실행 중 중단된 작업은 동일한 봉인 설정으로 재개했고, 재개 전 316문항의 원본 보존도 검증했다.

Astra는 이번 결과가 사전 ±0.02 기준의 동등성을 판단하기에 충분한 정보를 제공한다고 판단했다. 따라서 **현재 연구 질문을 위해 추가 GPU 실험을 진행할 필요는 없다. 별도 후속 설계는 최대 1회 중 0회 사용**으로 마무리했다.

원본·노이즈 뱅크·설정·로그·분석·코드 이력의 로컬 백업은 **8,382개 파일, 3,370,723,176바이트**를 검증했으며 누락과 해시 불일치는 0건이다. LOCK 커밋과 태그, 전체 코드 이력을 담은 Git bundle도 검증했다. GPU는 사용자 직접 반납 대상으로 안내했으며, 자동 반납을 실행하지 않았다.

## 해석의 범위와 한계

- 결론은 해당 모델, GSM8K, α=0.174, temperature=0.5, 고정된 생성·교란 설정과 주 AUROC 지표에 한정된다.
- 문제 단위 bootstrap은 현재 생성된 응답과 고정 설정을 조건으로 한다. 독립 생성 seed 반복이나 다른 모델·과제의 변동까지 평가하지 않는다.
- 탐지 대상은 Greedy 답의 오류 또는 INVALID이다. 모든 형태의 환각이나 실제 서비스 전체의 안전성으로 일반화하지 않는다.
- 승인된 V1.4 축소 범위를 완료한 것이다. 원래 PR1 확증, PR2a/b/c, PR3_T5/S, PR4, PR5, 원래 Holm 가설군, P2·boost 등 제외된 항목까지 수행했다고 주장하지 않는다.
- 별도 dev_anal C·D·E 생성 리허설은 생략했고, 선택에 쓴 dev_select 자료로 CPU 파이프라인을 점검했다. 이 점검은 독립 검증이 아니다.
- 검토는 AI 검토이며, 원래 요구된 인간 2인의 검토·서명은 충족되지 않았다.
- 외부 Hugging Face 캐시의 모델 가중치 파일 자체는 백업 범위 밖이다. 고정 revision과 모델·토크나이저 관련 해시 기록은 보존했다.

### 반납 전 추가 운영 관측

2026-11-16 후속 연구의 실행 환경을 확인하는 과정에서 프로젝트 밖 채굴 프로세스와 GPU 사용률 100%가 관찰됐다. 설치 주체와 실제 소유자는 확정하지 못했으며 임의 종료하지 않았다. 일부 프로세스의 기동 시각은 본시험 기간과 겹치지만, D의 중단 원인이나 개별 생성 결과에 대한 영향을 입증한 것은 아니다.

봉인 코드와 주요 산출물의 해시 일치는 별도로 재확인했다. 이는 파일 출처·보존 검증이며 시스템 전체의 무결성이나 과거 외부 작업의 모든 영향이 없었다는 증명은 아니다. 실행 시간은 전용 GPU 환경의 성능 측정값으로 일반화하지 않는다. 상세 관측과 접근 한계는 [외부 GPU 작업 진단 기록](../outputs/reproducibility/gpu_external_workload_diagnostic_20261116.json)에 남겼다.

사용자는 우선 GPU를 반납하고 완료 자료를 정리하기로 했다. 후속 연구는 질문 검토에 그쳤고 최종 등록·새 응답 생성은 없으므로 별도 후속 설계 사용은 0/1회다. 실제 GPU 반납 완료 여부는 확인하지 않았다.
